Free tools for Skyrim modding

These tools help you spend less time fixing your mods and more time playing.

ModPacer

Easily install new mods and keep them on pace with updates.

  • Check the SkyrimNet Plugin Hub and update your mods with one click.
  • Install new mods and see a clear list of what they need to run.
  • Works with both Vortex and Mod Organizer 2.
Get ModPacer Read the guide

Vortex Collection Tools

Everything you need to run massive Vortex collections without the friction.

  • Rebuild, update and clean up collections using clear step-by-step guides.
  • Merge plugins, find missing masters and fix load order cycles.
  • Runs next to Vortex and handles the manual steps for you.
Get Collection Tools

SkyrimNet MultiProxy

Cloud or Local. Paid or Free. Any AI, straight to SkyrimNet.

  • Link the AI of your choice to the game with a one-time setup.
  • Run local models with all your graphics card settings in one place.
  • Starts automatically in the background when you play.
Get MultiProxy

Vortex Bridge is a small extension that lets these tools talk to Vortex. It is included in both downloads so you do not need to get it separately.
